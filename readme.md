# Project Learning 🚀

This repository is created for learning and practicing DevOps tools and concepts.

## 📚 Technologies

### 🐳 Docker
- Build Docker images
- Run and manage containers
- Write Dockerfile
- Docker Compose
- Push images to registry

### 🤖 Jenkins
- Install and configure Jenkins
- Create Pipeline (Declarative & Scripted)
- CI/CD integration
- Connect Jenkins with GitHub
- Automate build and deployment

### ⚙️ Ansible
- Install Ansible
- Inventory configuration
- Write Playbooks
- Manage remote servers
- Automate deployment tasks

### ☸️ Kubernetes
- Pods, Deployments, Services
- ConfigMap & Secrets
- Ingress
- Helm basics
- ClusterIssuer & SSL (cert-manager)
- Deploy application to cluster


### 📦 Container Registries

-   🔹 GitHub Registry (GHCR)
    - Push and pull Docker images
    - Authenticate using GitHub Personal Access Token
    - Integrate with GitHub Actions

-   🔹 GitLab Registry
    - Built-in container registry
    - Integrated with GitLab CI/CD
    - Manage private and public images

-   🔹 Nexus Registry
    - Private repository manager
    - Store Docker images
    - Manage multiple repository formats (Docker, Maven, NPM, etc.)

-   🔹 Docker Hub
    - Public and private repositories
    - Official images
    - Image version management (tags)


## 🎯 Project Goal

The main goal of this project is to:

- Understand DevOps workflow
- Practice CI/CD pipeline
- Containerize applications
- Automate infrastructure
- Deploy applications to Kubernetes
- Manage container images using different registries
